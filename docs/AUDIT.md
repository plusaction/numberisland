## 검증 (수치)
- `pnpm check`: 타입·린트(경고 0)·레이어 경계·단위/속성/리플레이 테스트·빌드·오프라인 검사·용량 한도 통과.
- 단위 테스트 178개 통과, domain 커버리지(줄) 90.9%.
- e2e: 1차 수정 뒤 34/34 통과(WebGPU·WebGL2 두 프로젝트: 7개 스테이지 완주, 허브, 저장 유지, 설정 창, 튜토리얼, 힌트, 나가기). 2차 수정 뒤 재실행 결과는 PROGRESS에 기록.
- 직접 확인한 화면: 설정 창(데스크톱·폰), 결과 배지, 쉬는 시간 카드.
