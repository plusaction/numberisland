# 전략 선택지 (QUALITY96 G3)

각 스테이지에는 서로 다른 풀이 전략이 최소 2가지 있고, `tools/autoplayer/stages.ts`의 봇이 두 전략 모두로 밴드 A/B/C를 클리어함을 `tests/replay/gold-slice.test.ts` `[G3:*]`가 증명한다.

| 스테이지 | 전략 A | 전략 B | 위험/보상 |
|---|---|---|---|
| ③ 숫자 낚시 | 큰 물고기를 먼저 고르고 나머지를 맞춘다(목표 − 큰 수) | 작은 물고기부터 더해 간다(이어 세기) | 이상한 물고기(장화·오리·열쇠)를 잡으면 코인 +3이지만 집중이 흐트러진다(봇 B는 잡으러 감) |
| ① 폭탄 해체반 | 선을 왼쪽부터 차례로 자른다 | 가장 큰 수가 적힌 선부터 자른다(PLACE: 높은 자리 → 낮은 자리) | 정답 쌍이 여러 개인 판에서 어떤 쌍을 고를지 선택. 잘못 잘라도 다시 이어짐(벌칙 없음) |
| ④ 슬라임 합체 | 더하기 합체를 먼저 한다 | 빼기 슬라임(−k)을 먼저 써서 수를 줄인다 | 큰 수를 먼저 만들면 막다른 길에 갈 수 있음 → 되돌리기 무료·무제한 |
