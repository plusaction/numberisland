# PLAYTEST — 아이와 함께하는 관찰 (QUALITY96 §7)

결과는 `docs/HUMAN_INPUT.md`의 "점수" 칸에 적어 주세요. 비어 있으면 0점입니다.

## 준비물 (5분)
- 노트북/태블릿, 마우스 또는 터치. 소리 켜기(아이가 듣기 좋은 크기).
- `start.bat`(Windows) 또는 `pnpm preview` → 브라우저에서 `http://localhost:4173` 열기.
- 처음이면 "모험 시작!" → 괴물 친구 만나기(3~5문제)부터 아이가 직접.
- 이 종이, 연필, 타이머.

## 진행 (15~20분)
1. 섬에서 아이가 **스스로** 지역을 고르게 합니다(③ 낚시, ① 폭탄, ④ 슬라임이 열려 있음).
2. 첫 판은 튜토리얼(손가락이 보여 주는 장면)을 끝까지 보게 둡니다.
3. 아이가 막혀도 바로 도와주지 말고 **20초 기다립니다**. 그래도 막히면 "💡 힌트를 눌러 볼까?"만 말합니다.
4. 결과 화면 뒤에 아이가 "다시 하기"를 누르는지, 섬으로 가는지 **그대로 둡니다**.
5. 15분이 지나면 "오늘은 여기까지" 하고 끝냅니다.

## 끝나고 물어볼 질문 (유도 질문 금지 — 이 문장 그대로)
1. "제일 재미있었던 건 뭐였어?"
2. "어디가 어려웠어?"
3. "다음에 또 하고 싶어? 뭐 하고 싶어?" (A8)
4. "오늘 뭐 했는지 말해 줄래?" (A7)
5. "바꾸고 싶은 게 있어?"

## 하지 말 것
- 정답을 대신 말해 주기, "빨리 해" 재촉, 틀렸을 때 한숨/실망 표현.
- 다른 아이와 비교하기.
- 특정 스테이지로 유도하기.
