# 그래픽·성능 측정 (D16)

`pnpm shots` (Playwright, 1280×800, `?renderer=webgl&tier=…`)가 장면별 스크린샷과 `perf.json`을 이 폴더에 씁니다.
**주의:** 이 환경은 GPU가 없어 SwiftShader(CPU) 렌더링입니다. 드로우콜·삼각형·지오메트리/텍스처 수는 GPU와 무관한 실측값이고,
프레임 시간은 CPU 렌더링 값이라 **실기기 FPS가 아닙니다**(서로 비교용). 실기기 FPS·GPU 메모리는 `pnpm bench`(HUMAN).

- 드로우콜 감소: 외곽선 헐 제거, 정적 병합(재질별 1회), 덤불·열매 인스턴싱, 히트 프록시를 렌더 안 되는 레이어로 이동.
- 프레임 시간 증가는 PBR·환경광·절차 텍스처의 픽셀 비용(CPU 래스터라이저에서 크게 보임). 셰이더 내 노이즈 계산을 미리 만든 256² 텍스처 조회로 바꿔 절반 가까이 줄였음(2683→1166ms).
